# Stress-test worlds

Generated by `tools/gen_stress_worlds.py`. All worlds are in `content/world/stress/`, and the 128 colour material variants are in `content/material/stress/`.
Output is deterministic: if you run the generator again, you get the same files and UUIDs.

```bash
python3 tools/gen_stress_worlds.py                    # regenerate everything
python3 tools/gen_stress_worlds.py --only lights_256  # one world
python3 tools/validate_stress_worlds.py               # re-parse + cross-check every generated file
```

The generator writes the binary format directly. It covers the asset container from `compose_asset_file` and the `world_asset_handler` chunks, plus `entity_codec` CODEC_ENTT_V1 with `glt.transform / name / camera / light / mesh_renderer / hierarchy / sky / ambient_light`.
If a component layout changes in `ecs_world_plugin::on_load`, update the "component encoders" section of the generator to match.
The material variants are byte copies of `simple_color` with a new UUID, a new name and a different `CHUNK_MATERIAL_PARAMS` (base_color + roughness), so they all share one shader.

## Suggested comparisons

- **Scaling curves:** `instancing_1k → 10k → 50k` and `lights_64 → 256 → 1024`. Plot frame time against N. A super-linear curve points at an O(n²) path.
- **Load time:** time from opening each world to the first frame, especially `instancing_50k` and `streaming_grid`.
- **Save time:** saving `instancing_50k` is expected to be slow. `ecs_world::entity_id_for()` linearly scans all slots, and the region save calls it once per entity, so save is O(n²).
- **Editor usability:** the outliner, selection and gizmos with 50k named entities in `instancing_50k`.

## Mesh notes

- The `torus` mesh is only about 4 cm across, so the generator scales it ×25.
- Only `ball`, `cube` and `cylinder` have colliders.
- `stealth_ship` has 31 submeshes, so it is never given material overrides. The override count must equal the submesh count.
